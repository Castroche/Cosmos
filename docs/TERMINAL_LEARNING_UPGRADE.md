# 专业交易工作台与交易反馈升级

## 工作台

沿用 COSMOS 现有深色、青蓝配色。顶部展示监控品种、运行品种、持仓容量和现有风险上限；主工作区显示 K 线、计划价格与指标；右侧切换 BTC/ETH/SOL 合约并查看策略与量化信息。底部在组合持仓、活动计划、学习复盘、决策记录、市场分析和实盘授权间切换。

组合持仓同时显示全部品种，包含未成交与部分成交。浮动盈亏为行情价估算，不含尚未结算费用。至止损风险以最新价和有效止损估算，未成交部分计入预留。行情连接建立后，必须收到报价才显示实时；切换品种或周期期间不沿用旧 K 线。

研究、设置、策略编辑器等页面按需加载；主交易工作台无需先下载这些功能。

## 多品种与仓位分配

- 每个品种独立更新行情和运行决策，慢速 BTC 请求不阻塞 ETH/SOL。
- LLM 的 `position_state` 表示当前决策品种；`account_position_state` 单独表示整个账户。其他品种的仓位不能冒充当前品种的持仓管理对象。
- 同一服务进程内，账户分配和下单依次处理。前一个订单持久化后，下一个品种才读取最新的预算预留。部署继续使用项目的一进程运行方式，不支持以多个独立 API worker 同时执行同一账户。
- 优先使用交易所仓位和本地有效止损计算风险，以当前市值到止损的潜在损失对齐账户净值；缺少止损的账外仓位沿用配置的压力风险估算。
- 挂单和部分成交计入仓位容量与风险预算，交易所仓位与本地记录按品种、方向合并，避免重复计数。
- 资金不足以承载原始建议数量时，在现有杠杆、风险和最小数量限制内缩小订单。既有最大持仓数、最大回撤等上限不变。
- 持仓 Thesis 的覆盖检查使用其真实 `thesis_id`，避免把有持仓的观点误判成孤立观点。

## 自动学习闭环

```text
市场状态 → AI 策略 → 触发入场 → 保护单与持仓管理
    ↑                                  ↓
当前品种的历史经验 ← 版本化经验库 ← 平仓成交与成本后归因
```

完整平仓后自动生成经验版本；下一次决策读取该版本，并将 `learning_version` 和完整提示词哈希写入 DecisionEpisode。刷新失败不会增加交易审核门槛，已持久化的成交结果会在下次决策时重新处理。

经验按交易模式、品种、setup、入场行情状态和方向分组，统计成本后 R 收益、浮盈、浮亏，并生成入场和止盈建议。平滑胜率使用 Beta(2,2) 先验，平均 R 使用 10 个零收益先验样本收缩，防止少量胜负产生极端估计。这是在线更新的决策经验，不是基础 Quant 模型的自动重训，也不代表已经验证未来收益改善。

学习只接受 `COMPLETED`、具有完整买卖成交证据且存在已实现收益的记录。影子计划、未平仓、缺失成本后结果与未标记完整证据的旧数据不作为交易成绩。Demo 与 Live 经验隔离。统计窗口为最近 500 条完成记录，原始交易证据继续由现有账本保存；经验版本可追溯且重复处理不会新增相同版本。

量化模型原有预测、TTL 和开仓政策保持不变。交易计划目标与量化 Triple Barrier 标签不同，本升级不会将策略止盈命中率冒充基础量化模型的概率校准成绩。

## 审核与操作边界

保留原有开仓机制：MarketAnalyst + PortfolioTrader，不加入 Critic、额外回测前置或学习成绩门槛。学习没有否决开仓或修改风险上限的权限。Demo/Shadow 的 Quant 保持参考模式；现有 Live 授权、原生保护和账户限制保持原状。

升级代码不自动启动交易或签发实盘授权。构建前端后，重新启动现有服务即可加载代码；按现有流程操作 Demo。

新增只读接口：`GET /api/trading-intelligence/learning`。Overview 同时返回 `learning` 和 `portfolio_policy`。

## 核验依据

- [OKX API：账户与仓位模型](https://www.okx.com/docs-v5/trick_en/)：不同合约的仓位具有独立作用域，不能把账户整体持仓等同于当前合约持仓。
- [scikit-learn：概率校准](https://scikit-learn.org/stable/modules/calibration.html)：概率评分需对应实际标签和样本定义，不能用不匹配的策略结果直接证明模型已校准。

验证涵盖三品种分配、慢请求隔离、未成交风险预留、部分成交去重、保证金缩量、学习版本幂等、重启恢复、模式隔离、平仓到经验生成，以及下一次 Trader 提示词的经验版本追踪。浏览器使用独立临时数据库；含行情和持仓的验收截图使用明确的 UI 测试样本，不是账户业绩。
