# 应用分层与可验证学习升级（2026-10-31）

本次升级保持现有交易接口与风控边界，完成应用实例隔离、领域存储委托、带时间证据的学习辅助和不下单的在线影子对照。

## 应用与存储

- API 入口由 13,337 行缩减到 88 行，只负责应用装配。30 个领域服务模块承接业务编排，独立路由模块承接 HTTP/WebSocket；接口契约使用升级前的逐项哈希回归。
- `create_app()` 导入时不读取环境配置、凭证或 Git，不创建数据库；lifespan 创建实例依赖。测试显式注入应用服务，服务内状态不再挂在 API 模块全局变量上。
- SQLite 入口为 850 行显式委托及连接基础设施；9 个仓库共享同一个连接／锁所有者。原有事务和账户级串行边界保留。
- 仍只支持每账户一个执行进程，未增加多进程下单支持。

## 学习辅助

完整归因记录进入版本化经验库；缺失费用、收益或归因证据的记录不会用零值补齐。经验记录首次可用时间，决策按开始时间检索最多 5 个同模式、同品种案例，优先匹配行情状态。经验快照每 30 秒后台刷新，失败保留上一版本；旧版本缺少时间证据时保留展示，不作为可追溯的历史检索依据。

学习页面可关闭辅助、固定历史版本或恢复自动更新。决策记录保存经验版本、案例 ID 和上下文哈希。学习不自动改变风险限额、交易参数、策略准入或 Quant 模型。

## 在线影子对照

默认启用，在自动化运行且存在可用经验时按决策 ID 稳定抽样 10%，上海时间每天最多 10 组。每组最多一次 Trader 请求和一次格式修复；对照不重试 HTTP 请求、不自动切换厂商。并发为 1，队列最多 10 组，60 秒超时。额度原子预留并跨重启保留；未完成请求在重启后记为中断，不重复调用付费接口。

两组复用 Analyst、行情、账户、Quant 与计划输入，只改变学习上下文；模型配置变化导致对照失败而不会使用不同配置继续比较。对照结果不会创建计划、等待条件、订单或持仓，也不会被学习为真实交易经验。

后续 24 根完整 5m K 线提供方向收益、MFE 和 MAE。它们是价格代理指标，不包含成交、手续费或滑点，不是交易利润。缺口标为不可评估，非方向决策不虚构交易。少于 30 组完成对照时显示样本不足；更多样本也只构成观察性证据，不自动认证或晋升策略。费用未知时明确显示未知。

## 运行与迁移

- Git 构建身份读取显式采用 UTF-8，中文及特殊文件名不会再受 Windows 默认 GBK 影响。Git 失败仍阻止创建无法验证的运行身份。
- 数据库增量升级到 v11；首次迁移前创建并校验备份，重复启动不反复备份。历史交易表与证据不删除。
- 当前工作台为本机免登录模式，保留 Host、Origin、Fetch Metadata 检查；旧文档的密钥配对／会话描述已标注为历史行为。Live 执行继续硬拒绝。
- 停止自动化先使入场代次失效，再取消影子任务。关闭对照或固定旧经验即可回退学习行为；回退代码保留新增证据，不覆盖仍在使用的账户数据库。
